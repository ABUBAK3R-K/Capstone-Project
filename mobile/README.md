# Mobile Application (/mobile)

This directory contains the mobile application codebase, built using **Flutter (Dart)**. It targets Android devices and provides the main interface for community users and local authorities.

## 🧑‍💻 Owner
* **Role:** Mobile Developer
* **Responsibilities:** Flutter app layout, OpenStreetMap integration via `flutter_map`, Supabase authentication flow, civic problem camera interface/reporting, and rendering recommendations.

## 🛠️ Stack & Key Packages
* **Framework:** Flutter (Dart)
* **Map:** `flutter_map` (OpenStreetMap tile provider)
* **State Management:** `provider` or `flutter_riverpod` (depending on final team selection)
* **Backend Link:** `supabase_flutter` for Auth, DB listening, and Storage uploads

## 📂 Directory Contents
*(Future setup will populate standard Flutter project structure)*
* `/lib`: Application source files (UI, state, models, services)
* `/assets`: Graphics, fonts, and local geojson templates
* `/android`: Native Android configuration files
